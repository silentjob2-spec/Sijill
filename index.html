ربط الموقع مع Google Sheets

بعد نشر Google Apps Script كتطبيق ويب، ضع الرابط هنا. الموقع سيحفظ محليًا أيضًا، ويمكنك المزامنة يدويًا أو تلقائيًا.

ملاحظات مهمة

  • Google Sheets هي قاعدة البيانات المركزية، بينما GitHub Pages يستضيف ملفات الموقع فقط.
  • لا تضع كلمة مرور Google داخل الموقع.
  • يمكنك الاحتفاظ بنسخة Excel/Google Sheets ونسخة JSON احتياطية.
  • الصور المرفقة بحالات السلوك تُزامن أيضًا مع Sheets، لكن خلايا الجداول محدودة بحوالي 50 ألف حرف؛ الصور الكبيرة جدًا قد تفشل مزامنتها رغم أن الموقع يضغطها تلقائيًا.
