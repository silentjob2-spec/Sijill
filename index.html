ربط الموقع مع Google Sheets

الرابط الحالي ثابت ولا يتغيّر. لتحديث الكود مع الإبقاء على نفس الرابط: الصق Code.gs ثم Deploy → Manage deployments → أيقونة القلم على النشر الحالي → Version: New version → Deploy.

ملاحظات مهمة

  • Google Sheets هي قاعدة البيانات المركزية، بينما GitHub Pages يستضيف ملفات الموقع فقط.
  • المزامنة تلقائية عند فتح الموقع وعند أي تعديل — يمكنك أيضًا المزامنة يدويًا من الأزرار أعلاه.
  • لا تضع كلمة مرور Google داخل الموقع.
  • يمكنك الاحتفاظ بنسخة Excel/Google Sheets ونسخة JSON احتياطية.
  • الصور تظهر داخل عمود image في الـ Sheet كصورة (دالة IMAGE). الملف الأصلي يُحفظ في مجلد Drive «نظام إدارة الطلاب - صور السلوك» لأن حد الخلية ~50 ألف حرف ولا يتسع للصورة كاملة.
  • مهم: الصق Code.gs، شغّل createDatabaseSpreadsheet() إن طُلبت صلاحيات Drive، ثم Deploy → Manage deployments → Edit على النشر الحالي (نفس الرابط) → New version.
