### 📦 ماذا ترفع على GitHub؟ (من صورتك الأخيرة)

افتح مجلد `student_management_v15` وارفع فقط:

```
sijil/
├── .nojekyll          (ضروري جداً - لا تحذفه)
├── index.html         (غيّر اسم `index` إلى `index.html`)
├── app.js             (غيّر اسم `app` إلى `app.js`)
├── style.css          (غيّر اسم `style` إلى `style.css`)
├── database.json
└── README.md          (هذا الملف)
```

**لا ترفع:** ملف `Code` وملف الاكسل `student_management_google_sheets...` و `README-GOOGLE-SHEETS.md`

### 🔧 التشغيل

**1. GitHub Pages:**
1. أنشئ مستودع جديد باسم `sijil`
2. ارفع الملفات الستة
3. Settings > Pages > Deploy from a branch > main / root
4. افتح رابط الموقع

**2. ربط Google Sheets (مرة واحدة):**
- `script.google.com` > مشروع جديد > الصق كود `Code` > احفظه باسم `Sijil Backend`
- شغّل `createDatabaseSpreadsheet` > وافق > انسخ رابط الشيت من Execution log
- Deploy > New deployment > Web app > Execute as Me > Anyone > انسخ رابط /exec
- ارجع لموقع سِجِل > الإعدادات > الصق رابط /exec

### 📖 ملاحظة الحفظ

- GitHub Pages موقع ثابت، لا يكتب في `database.json` مباشرة
- البيانات تحفظ في متصفحك `localStorage`
- للنقل بين الأجهزة: استخدم زر النسخ الاحتياطي داخل الموقع، أو اعتمد مزامنة Google Sheets
